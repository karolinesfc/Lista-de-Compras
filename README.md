## 📌 Sobre o projeto

O **Lista de Compras** é um aplicativo mobile criado para facilitar a organização de produtos durante as compras. Com uma interface simples e intuitiva, permite adicionar produtos, definir quantidades e remover itens quando necessário.

O projeto foi desenvolvido como atividade prática de Desenvolvimento de Sistemas, com foco na criação de componentes, gerenciamento de estados e organização do código.

## ✨ Funcionalidades

* ➕ **Adicionar produtos:** cadastre novos itens na lista.
* 🔢 **Definir quantidades:** informe quantas unidades deseja comprar.
* 🗑️ **Remover produtos:** exclua itens da lista facilmente.
* ⚠️ **Validação de campos:** receba um alerta ao tentar adicionar um produto sem nome.
* 🧺 **Lista vazia:** visualize uma mensagem quando não houver produtos cadastrados.
* 📊 **Contador de itens:** acompanhe a quantidade de produtos na lista.

## 🚀 Como executar o projeto

**1. Clone o repositório**

```bash
git clone URL_DO_SEU_REPOSITORIO
```

**2. Entre na pasta do projeto**

```bash
cd lista-de-compras
```

**3. Instale as dependências**

```bash
npm install
```

**4. Inicie o aplicativo**

```bash
npm start
```

Depois, utilize o Expo Go no celular ou um emulador compatível para executar o aplicativo.
